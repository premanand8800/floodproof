# Prototypes

Early exploration scripts (search loop, reverse-image probes, matcher prototype) that preceded `src/floodproof/`. Kept for history; the product code does not import them. Run from the repository root, e.g. `python prototypes/t1.py`, so the relative `bench/` and `.cache/` paths resolve. The matcher prototype's rules live on in `src/floodproof/matcher.py`.
